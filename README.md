## About

I build focused tools and experiments in Rust and Python. I’m interested in Linux systems, expressive terminal interfaces, and practical defensive security.

## Selected work

### [ProcScape](https://github.com/violatedheart/procscape)

A native Rust app that turns live Linux process data into a colorful, periodically refreshed wallpaper. It includes a CLI, daemon, and optional GTK dashboard.

### [Algotype](https://github.com/violatedheart/algotype)

An offline terminal typing trainer in Rust and Ratatui, with adaptive practice and locally saved progress.

### [Keyguard](https://github.com/violatedheart/Keyguard)

A read-only Windows keylogger-detection experiment, with a Linux sandbox that mocks Windows APIs for testing. **Work in progress.**

<a id="projects"></a>
### `$ ls ~/projects`

#### [ProcScape](https://github.com/violatedheart/procscape) · `Rust` `Linux`
Turns live Linux process data into a colorful, periodically refreshed wallpaper. Includes a CLI, daemon, and optional GTK dashboard.

#### [Algotype](https://github.com/violatedheart/algotype) · `Rust` `Ratatui`
An offline terminal typing trainer with adaptive practice and locally saved progress.

#### [Keyguard](https://github.com/violatedheart/Keyguard) · `Windows` `security` `WIP`
A read-only keylogger-detection experiment, with a Linux sandbox that mocks Windows APIs for testing.
